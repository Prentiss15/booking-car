# ระบบจองรถเดินทาง (Vehicle Booking System)

ระบบจองรถสำหรับการเดินทางเป็นรอบ หรือเดินทางประจำเดือน รองรับทั้ง **รถตู้ (10 ที่นั่ง VIP)** และ **รถบัสปรับอากาศ** พัฒนาด้วย PHP 8.4 + SQLite3 + Tailwind CSS ใช้งานง่าย ไม่ต้องติดตั้งโปรแกรมเพิ่ม

---

## ฟังก์ชันการทำงานหลัก

### 1. ระบบจัดการสำหรับ Admin (`/admin`)
- **เลือกประเภทยานพาหนะที่จะจัด**: เลือกระหว่าง **รถตู้ 10 ที่นั่ง (VIP)** หรือ **รถบัส (ค่าเริ่มต้น 40 ที่นั่ง ปรับได้)**
- **กำหนดจำนวนคัน**: ระบุจำนวนคันที่ต้องการ (เช่น รถตู้ 2 คัน, รถบัส 1 คัน) ระบบจะสร้างคันรถและผังที่นั่งให้อัตโนมัติ
- **ระบบคำนวณวันอาทิตย์ต้นเดือน**: แนะนำวันอาทิตย์แรกของแต่ละเดือนโดยอัตโนมัติ พร้อมปุ่มคลิกเลือกรอบล่วงหน้า 6 เดือน หรือเลือกเปลี่ยนวันที่ได้ตามต้องการ
- **จัดการข้อมูลคนขับและรถ**: แก้ไขชื่อคนขับ, เบอร์ติดต่อ, และเลขทะเบียนรถ
- **ส่งออก/พิมพ์ใบรายชื่อ**: มีปุ่ม "พิมพ์ใบรายชื่อ" สำหรับพิมพ์หรือบันทึกเป็น PDF เพื่อส่งให้พนักงานขับรถเช็คชื่อ

### 2. หน้าลงชื่อจองรถ (`/index.php`)
- แสดงข้อมูลรอบเดินทาง เวลาล้อหมุน จุดนัดพบ และจุดหมายปลายทาง
- แสดงการ์ดรถแต่ละคัน พร้อมแถบแสดงสถานะจำนวนที่นั่งว่างแบบเรียลไทม์
- **ผังที่นั่งเสมือนจริง (Interactive Seat Map)**:
  - ผังรถตู้ 10 ที่นั่ง (ด้านหน้ารถ + ที่นั่ง VIP เบอร์ 1-10)
  - ผังรถบัส (แบ่งแถวซ้าย-ขวา พร้อมทางเดินตรงกลาง)
  - สีเขียว = ที่นั่งว่าง (คลิกเพื่อเลือก)
  - สีน้ำเงิน = ที่นั่งที่กำลังเลือก
  - สีเทา = มีผู้จองแล้ว
- ฟอร์มกรอกชื่อ-นามสกุล เบอร์โทรศัพท์ แผนก/สังกัด และหมายเหตุ
- ระบบป้องกันการจองซ้ำ (ป้องกันการแย่งที่นั่งเดียวกัน และแจ้งเตือนหากเบอร์โทร/ชื่อเคยลงชื่อในรอบนี้แล้ว)

### 3. หน้าตรวจสอบว่าเราได้ลงชื่อไปแล้วคันไหน (`/check.php`)
- ค้นหาด้วย **ชื่อ-นามสกุล** หรือ **เบอร์โทรศัพท์**
- แสดงการ์ดข้อมูลว่า:
  - เราได้ลงชื่อไปใน **รถคันไหน** (เช่น รถตู้ คันที่ 1 ทะเบียน ฮฮ-1234)
  - **หมายเลขที่นั่งใด**
  - ชื่อคนขับและเบอร์ติดต่อ จุดนัดพบ และเวลารถออก
- ระบบยกเลิกการจอง โดยต้องยืนยันด้วยเบอร์โทรศัพท์ที่ใช้ลงชื่อ
- แสดง **รายชื่อผู้ร่วมเดินทางทั้งหมดแยกตามคันรถ** ตรวจสอบได้ว่าใครนั่งคันเดียวกันบ้าง

## วิธีเปิดใช้งานบน Windows

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `start.bat`
- ดับเบิลคลิกที่ไฟล์ `start.bat` ในโฟลเดอร์นี้ ระบบจะเริ่มเซิร์ฟเวอร์ PHP และเปิดเว็บเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:8000`

### วิธีที่ 2: รันผ่าน Command Prompt หรือ PowerShell
```bash
php -S localhost:8000
```
จากนั้นเปิดเบราว์เซอร์ไปที่:
- หน้าลงชื่อจองรถ: `http://localhost:8000/index.php`
- หน้าตรวจสอบสถานะ: `http://localhost:8000/check.php`
- หน้าจัดการสำหรับ Admin: `http://localhost:8000/admin/index.php`
